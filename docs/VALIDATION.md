## 安装与执行环境

- **Godot 4.6.3**：官方 `4.6.3-stable` 源码，本地编译得到 `4.6.3.stable.custom_build` 编辑器/无头验证程序。
- 当前沙箱编译关闭了 X11、Wayland、Vulkan、OpenGL 驱动和 fontconfig；用于资源导入、脚本、物理及逻辑回归，**不是这里可交互游玩的图形版**。
- 编辑器初始化会记录“未编译 fontconfig、系统字体不可用”的环境诊断；玩法/动作套件本身通过。Windows 官方标准版不使用这套受限编译配置。
- **Blender 5.0.1**：官方 PyPI `bpy` 后台模块；补齐 X.Org/OpenGL 依赖后，通过本地 CLI 适配器实际执行建模、导出、审计和 Cycles CPU 渲染。**没有把它说成完整 Blender GUI 安装。**
- 官方二进制站点与系统软件源连接失败，因此采用上述源码/模块方式。安装包、源码和工具链留在本地缓存，不进入仓库。
