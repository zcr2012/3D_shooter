# 《寂静港口》Windows 试玩版

下载 `SilentHarbor-Windows-x64` 构建附件后**完整解压**，运行 `SectorNine.exe`。无需安装 Godot。
这是未签名的原创首关开发版；Windows 可能提示未知发布者。请核对本仓库 Actions 来源，不要关闭系统安全软件。

## 操作
- 回车开始；WASD 移动，鼠标观察，左键射击，R 换弹。
- E 操作目标／补给；按屏幕提示完成门禁、报警线路、救人与撤离。
- Esc 真正暂停／恢复；失焦自动暂停。在菜单中调整音量、灵敏度、字幕、阴影和全屏。
- F6 阴影开关；F7 配音开关。笔记本可能需要同时按 Fn。
- 救人后 H：让陈默原地等待／恢复跟随。撤离必须人和证据一起到达，不能独自跑到终点。
- 每个阶段入口自动保存；启动简报按 C 继续，失败后回车重试最近检查点。
- 重试重置当前阶段敌人，保留已使用补给、弹匣和统计；生命至少恢复至 60、备弹至少 30，防止检查点缺弹卡关。不会直接补满弹匣。
- 暂停菜单可以确认后从头重开；成功撤离后清除检查点。

## 存档和低配
设置与阶段存档在 `%APPDATA%\SectorNine\`，JSON 带版本检查和上一份备份。它不是任意时刻快速存档。
使用兼容渲染器；核显可先关闭太阳阴影。尚未获得你的机器上的帧率、声音听审和完整人工通关结果。

## 内容与限制
本版含中文内置字体、八段合成中文对白、程序生成音效、程序镜头过场、战术敌人与护送流程；证人陈默为带骨骼动画的程序化 Blender 模型（跪姿、奔跑、待机、求助）。
CI 已完成自动回归与导出冒烟启动，但这不等于真人试玩验收；欢迎反馈画面、帧率、声音与卡关问题。
配音不是专业演员棚录，过场没有完整口型演出；本版不是完整商业级游戏。
