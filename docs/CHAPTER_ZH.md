# 寂静港口：中文叙事与战术迭代

本轮继续改进同一个首关，不将开发切片包装为商业成品。

## 中文与配音

- 城市关和旧仓库关的菜单、HUD、任务、提示、结算、敌人状态及世界标识改为中文。
  WASD、Ctrl、Shift、Tab、F6 等仍保留真实键帽名称；内部资源名/调试日志不作为游戏文案翻译。
- 工程内置 **Noto Sans CJK SC** 字体及 **SIL OFL 1.1** 许可和来源哈希，不依赖 Windows 已安装的字体。
- 字幕按 Unicode 字符和实际字宽换行，解决中文没有空格时整行溢出的问题。
- 用户试听选择了两位中文合成声音：指挥员、证人陈默。共 8 段对白，文本与音频映射保存在
  `godot_project/data/zh_dialogue.json` 和音频目录中的 manifest。
- **F7** 开关配音，字幕与任务照常推进；按住 **Tab** 查看最近四段行动记录。
  **查看行动记录不暂停战斗**，请先进入安全位置。
- 声音是 AI 合成，不冒充实名演员或专业录音棚作品。生成声音的商用使用仍须遵守相应服务条款。

## 剧情重新梳理

| 时间 / 节点 | 线索与行动 |
|---|---|
| 05:06 | 门禁系统收到封锁命令。现场终端旁能看到这条记录。 |
| 05:12 | 北码头选择性停电，武装承包商控制街道。封锁早于停电，说明停电不是临时事故。 |
| 05:40 | 先遣警员林舟进入街区，指挥中心交代证人陈默及失踪人员线索。 |
| 门禁 | 获取记录，确认预谋封锁；新的目标是切断武装人员的报警上行。 |
| 中继 | 切断的是报警链路，不是仓库供电。独立应急电源解释了为何仓库仍有照明。 |
| 营救 | 陈默说明身份、为何复制清单、为何仍被扣押；玩家取得运输记录副本。 |
| 护送 | 增援通报、存储卡内容、接应指令分别触发；记录指向今晚的下一次转运。 |
| 结尾 | 证人接应与数据校验完成，留下调查方向，而不是突然宣布整个案件已解决。 |

证据取得通过任务状态、HUD 和对白表现；尚未制作手递手存储卡动作或可查看的物品模型。

## 可跳过的引擎内过场

1. 开场沿默瑟街的镜头与指挥中心简报。
2. 营救时靠近陈默的镜头与身份说明。
3. 接应区收尾镜头与证据校验。

**空格或回车跳过**。过场冻结玩家与敌人的战斗控制；恢复时重新启用正确的相机、任务阶段和输入门控。
不是预渲染电影，尚无面部口型、完整角色表演或电影级剪辑。

## 场景与人物美术

新增窗框层次、百叶卷帘、遮雨棚、排水管、屋顶设备、仓库支撑梁、中文店招和警务接应车。
车辆方块轮胎换为合批圆柱轮胎/轮毂。增加 6 组高掩体及 24 个供 AI 校验的候选位置。

陈默增加织物法线材质、安全帽和反光条，增强码头工人与武装人员的轮廓区分。
本轮这些细节在 Godot 中以程序几何和材质覆盖制作，保留原 Blender 源文件，**没有声称重新完成写实人物雕刻**。

## 战术 AI

- 有限视野、近距离感知、枪声调查和附近同伴通报。
- 失去视线后使用最后已知位置；不会把记忆位置当作可以直接伤害玩家的依据。
- 受伤或侧移角色选择经过遮挡和路径校验的掩体，同伴不能重复占用同一位置。
- 移动至掩体、短暂停留、寻找侧边探头位置；射线被同伴挡住时不向玩家结算伤害。
- 连续射击后有真实的装填停顿，不在换弹过程中持续造成伤害。

这是有限状态与作者布置的静态掩体网格，不是完整战术规划器、动态破坏导航或拟人化团队指挥系统。

## 声音制作

新增 7 条原创合成音效：室外/室内枪声、脚步、弹匣机械声、终端反馈、受伤提示、码头环境底噪。
敌人枪声采用三维播放；对白与音效分离，讲话时降低音效音量，主总线增加峰值限幅。

音效脚本为 `scripts/build_chapter_audio.py`。这些是分层合成素材，**不是专业外录枪声、配乐或已完成的最终混音**。
需要 Windows 设备上的实际音量、空间定位与耳机/扬声器试听验收。

## 验证

原有三个引擎套件保留，城市旧套件显式关闭过场，避免跳过测试主体。
新增 `verify_chapter_zh.gd` 验证中文字体/排版、音频资源、过场跳过和自动恢复，以及 AI 视野、掩体、同伴通报、换弹和墙体遮挡。
实际结果：专项 33/33、城市 47/47、旧玩法 31/31、动作 374/374、Python 14/14 通过。
证据和边界见 [本轮验证记录](CHAPTER_ZH_VALIDATION.md)。

运行：`python tools/project.py verify`；完整性检查：`python -m unittest discover -s tests -v`。
新轮 Windows 图形画面、声音、真实帧率与完整人工通关仍须另行验收。
