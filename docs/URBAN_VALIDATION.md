## 47 项检查覆盖什么

- 简报控制门控、第一人称相机高度、隐藏第三人称身体、模型挂点、静态合批预算。
- 真实物理帧中的 ADS 视场角/枪械位置、Ctrl 蹲起、胶囊体变化及站起遮挡。
- 实际换弹期间的左手/弹匣位移、不提前发弹、动作结束后原子结算弹药。
- 真实物理世界的眼部射线命中、近墙挡弹、敌人视线遮挡。
- 门禁不能跳阶段、分区激活、一次性补给、死亡碰撞关闭、倒地动画导入。
- 两道门解锁、营救、增援、护送路径不进入膨胀后的静态障碍、线人实际移动。
- 撤离等待线人、10 名敌人计数、胜利后禁火、重新实例化恢复初始状态。
- 新敌人在真实物理帧中的发现延迟与自主开火、玩家死亡后结束任务并关闭 AI。

测试部分阶段使用直接交互调用、传送和冻结 AI 控制变量，不声称已由真人从头到尾通关。
视线测试发现贴近玩家的障碍可能落在玩家胶囊内部，已将新敌人的视线改为检查眼部目标前的环境遮挡，避免提前命中玩家胶囊而忽略墙体。

## 环境和诊断

- Godot 4.6.3 官方源码编译的 Linux 无头版本；本地补齐 ETC/BC 纹理压缩导入支持。
- 无 OpenGL/Vulkan 图形驱动，不用于 GPU 画面验收。
- 干净编辑器导入仍记录缺少 fontconfig / 系统字体、本地化和编辑器主题颜色的环境诊断。
  没有脚本解析或玩法运行错误；不得将它描述为“整个导入日志完全无警告”。
- Blender 5.0.1 官方 `bpy` 后台模块，实际运行生成、导出、审计和 CPU 渲染；不是完整 GUI 工作站。
- 引擎源码、二进制、依赖与安装缓存均不进入工程交付。
