# 城市首关：寂静港口 / Silent Harbor

本轮新增的是**第一人称首关开发切片**，不是完整战役，也不宣称达到商业发行或《使命召唤》的制作水准。
默认入口改为 `scenes/urban_operation.tscn`；旧仓库关 `scenes/mission.tscn` 和动作测试关 `scenes/main.tscn` 保留。

## Windows 试玩

用 Godot 4.6.3 打开 `godot_project/project.godot`，等待首次导入，再点击右上角 **▶**。
笔记本可以用 **Fn + F5**；不需要重新安装工程或单独运行 Blender。

| 操作 | 按键 |
|---|---|
| 部署 / 失败或完成后从头重开 | Enter，或点击 DEPLOY / RETRY |
| 行走 / 冲刺 / 跳跃 | WASD / Shift / Space |
| 蹲下躲避矮掩体 | 按住 Ctrl；头顶受阻时不强行站起 |
| 开火 / 瞄准 | 鼠标左键单发 / 按住右键 |
| 换弹 | R；完成动作才补充弹匣，受击可打断 |
| 使用终端、救人、补给 | 靠近后按 E |
| 释放鼠标 | Esc；**不会暂停敌人**，点击重新捕获 |
| 核显减负 | F6 切换太阳阴影，笔记本可能需要 Fn + F6 |

界面及电台字幕目前为英文，下面提供中文剧情说明。没有配音。

## 地图和任务

地图边界约 **92 × 140 米**；主要可步行战斗路线为中央街道和仓库，
两侧楼体主要是不可进入的背景建筑。**不是所有建筑可进入的开放世界。**
街道包含路沿、窗格、门禁、路灯、停车车辆、路障及补给箱。
静态建筑按材质合批，兼容渲染器，不依赖体积雾、实时全局光照或重型后处理。

1. **默瑟街封锁线**：从南端出发，清除本区域 3 名守卫，到门禁终端按 E。
2. **北码头中继站**：继续沿街前进，清除 3 名守卫，在仓库外东侧黄色控制箱按 E，打开仓库门。
3. **仓库营救**：进入有屋顶的内部空间，清除 2 名守卫，靠近仓库深处的线人按 E。
4. **护送撤离**：电台提示增援，沿原路返回；途中 2 名增援。到南端绿色撤离区，
   清除当前接触、等待线人一同到达才完成。线人有避开静态障碍的网格寻路，当前不会受到伤害。

起点东侧及仓库外有一次性补给，各提供 **60 发备弹和最多 40 点生命**；不直接填满弹匣。
HUD 顶部有目标方向、距离及本阶段剩余接触数，不再显示透视敌人的全知雷达。
尚无中途存档；失败从本章开头重来。

## 原创剧情梗概

05:12，北码头发生了选择性停电。地方巡逻赶到前，道路已经被提前封锁。
一名码头工人发现标为“空箱”的货柜内传出人声，复制运输清单后遭安保承包商扣押。
玩家作为先遣警员进入街区，切断仓库中继，救出证人并带回运输记录。
电台在进入封锁线、穿过街区、进入仓库和返回撤离点时补充线索。
本章结尾只留下后续调查的线索，**没有把未制作的下一章算作已完成内容**。

## 美术与动画

- Blender 原创近景武器、左右手臂、独立手指形体、枪械硬表面和可移动弹匣：`outputs/urban/fps_kit.blend`。
- ADS、步行晃动、后坐力、枪口闪光、近墙压枪、换弹手臂/弹匣位移在 FPS 适配脚本中驱动。
  目前是刚性部件动画，**不是完整手指骨骼或精确换弹接触解算**。
- 敌人沿用经过回归的 22 骨角色，制作独立暖棕布料版本，移除 SWAT 字样，
  新增 `StrafeArmed` 横移循环及 `FallArmed` 倒地动画。源文件 `outputs/urban/contractor.blend`。
- 线人为新制作的简化平民模型，使用独立腿部枢轴行走：`outputs/urban/witness.blend`。
- 免费布料材质来自 **Poly Haven / CC0**，下载镜像、固定版本、原始文件及 SHA-256
  保存在 `third_party/polyhaven/`。道路/墙面为原创程序纹理，未混入许可不明的“免费”资源。
- `outputs/urban/fps_preview.png` 是 **Blender 离线模型预览，不是游戏截图**。

## 距离商业级还缺什么

目前模型、车辆及建筑仍偏简化；没有影视级角色、动作捕捉、面部动画、完整 IK、
环境叙事细节、专业音效、配音、过场、丰富战术 AI 或多章节内容。
敌人使用有限横移/巡逻和视线射击，不是完整掩体协作系统；只有线人使用障碍网格寻路。

核显优化只是设计约束，**不是已测出的帧率保证**。需要在你的 Windows 电脑上确认画面、
瞄准手感、枪械穿插、路径卡住情况、内存和帧率，再决定下一轮美术精修和性能预算。
无头逻辑测试不能替代这些验收。

## 制作工具

运行游戏不需要 Blender 或 Pillow。重新生成美术时需要 Blender 5.x，且其 Python 环境可导入 Pillow；
可通过 `BLENDER_BIN` 指定 Blender 可执行文件。

```text
python tools/project.py model-urban   # 生成三个模型及新动画审计
python tools/project.py audit-urban   # 重新审计已有源文件
python tools/project.py render-urban  # CPU 渲染 FPS 模型预览
python tools/project.py verify        # 导入 + 旧动作 + 旧关 + 新城市关测试
```

`model` / `audit` / `render` 仍针对旧 v09 角色，并未偷偷改成新模型命令。
Blender 源文件里的 `LeftArm`、`Magazine`、`LegLeft`、`LegRight` 名称是运行时动画接口，编辑时请保留。
